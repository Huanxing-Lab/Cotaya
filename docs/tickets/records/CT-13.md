开发迭代中被测试捕获并修复的真实缺陷 3 处:
  ①领域 limitKind cycle_token 与 wire 枚举 cycle_tokens 不一致：单轮 token 超限的 denial

  ②并发拒绝通知撞「同轮唯一 pending」部分唯一索引直接抛错（第二个 actor 的挂起通知失败，
    其等待无人解除）→ 冲突重读合并；且合并语义改为字段并集（费用+token 两侧事实都保留，
    后到者不覆盖先到者的 currentLimit）；
  ③重复回答幂等断裂：恢复成功后的同回答重放被 program_not_runnable 拒绝；同 version 不同
    grant 的「异答」被当 no-op 吞掉（存在借旧 version 换更大扩额的口径风险）→ running 幂等
    回执 + 异答 version_conflict；
  ④wireSuspendForChangeLimit 漏带 leaseEpoch（schema 收紧后的运行期 parse 失败）→ 复查
    发现并修复，change_limit 用例回归。
